# Feature: Internal Comment (UI)
**Owner:** Frontend | **Module:** Comments & Attachments

## Goal
Let agents/admins leave notes only visible to staff.

## Scope
- Part of `components/CommentBox.tsx` — a toggle/tab for "Internal note" vs "Reply to customer", visible only to agent/admin roles.
- Internal comments rendered with a distinct visual style (e.g. yellow background) so staff never confuse them with customer-visible replies.
