# Feature: Alert / Notification Display (UI)
**Owner:** Frontend | **Module:** SLA Timer & Alerts

## Goal
Let agents/admins see SLA breach warnings without digging through every ticket.

## Scope
- A small notification/badge in the shared layout header showing count of at-risk/breached tickets.
- Optional toast/pop-up when a new breach notification arrives.
- Data comes from backend alert endpoint — this feature only renders it.
